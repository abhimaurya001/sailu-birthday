# SAILU 3D Birthday Surprise 🎂✨

## Requirements
- Node.js installed

## Run on Windows PowerShell

```powershell
cd "C:\Users\ak131\OneDrive\Desktop\sailu-birthday-3d"
npm install
node server.js
```

Then open:

http://localhost:3000

## Project structure

sailu-birthday-3d/
├── server.js
├── package.json
└── public/
    └── index.html

The birthday name/date/message are served by:
GET /api/birthday

Change them in `server.js` if needed.
